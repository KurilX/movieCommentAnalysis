# 05: TF-IDF 补全真正的 IDF

**What to build:** 关键词权重从「只有 TF」改成真正的 TF × IDF。IDF 以单条评论为文档、在全部 4000 条评论上计算，让「电影」「觉得」这类全站通用词被自然压低，而不是仅靠停用词表硬挡。

**Blocked by:** 04（必须先有正确分词，否则 IDF 是在错误 token 上算的，白算）

**Status:** done

- [x] IDF 以单条评论为文档、全库 4000 条评论为语料计算；使用平滑形式避免除零
- [x] 权重 = TF × IDF，返回的 `weight` 字段即为该值（字段名与契约不变）
- [x] 停用词表保留（挡住单字虚词），通用高频词的抑制主要交给 IDF

- [x] 测试：单文档语料不除零、不返回 NaN/Infinity
