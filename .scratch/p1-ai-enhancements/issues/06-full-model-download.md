# 06: 后台可下载完整版语言模型（不可用时自动降级 portable）

**What to build:** 在后台数据管理页给管理员一个「下载完整版语言模型」的入口，能一键把 HanLP 完整版数据包下到本机并在下次启动时自动启用；没下载或下载失败时系统照常以 portable 运行，绝不报错。演示路径永远走 portable。

**Blocked by:** 04（portable 必须先接上并成为可用基线，否则「降级」无处可降）

**Status:** done

- [x] 后台数据管理页新增按钮区块，**仅 ADMIN 可见**，显示当前状态：未下载 / 下载中 / 已就绪 / 失败
- [x] 显示当前实际生效的分词器标识（portable 还是完整版），便于演示前一眼确认
- [x] 后端代理流式下载 HanLP 官方数据包到本地目录，目录加入 gitignore，不进 Git
- [x] 启动时检测该目录是否有有效数据集：有则加载完整版，无则降级 portable
- [x] 下载过程中/失败后系统主流程不受影响，仍可正常提取关键词；按钮支持重试
- [x] 不做断点续传、不做校验和验证（失败即重试）
- [x] 状态查询与下载触发两个接口走现有 `/api/admin/**` 约定，受 ADMIN 权限保护；普通用户访问返回 403
- [x] 测试：语言模型目录不存在时关键词提取仍正常返回结果、不抛异常
- [x] 测试：目录存在伪造数据集时启动不崩溃（无论是否真的启用完整版）
- [x] 测试：非 ADMIN 调用下载接口返回 403
